仓库连接 · GitHub

连接 GitHub 仓库后，所有修改会直接提交并触发 GitHub Pages 自动重建。
Token 需要 public_repo（公开仓库）或 repo 权限。仅保存在本浏览器 localStorage，并直接发往 api.github.com，不会经过任何第三方。

快速访问

连接仓库后显示线上地址。

添加车型

保存后会自动提交并同步到前端。
编辑中：
上传文件会提交到 assets/，并自动填入上方 URL。

车型列表

点击卡片上的「编辑」可载入左侧表单修改；「下架」仅在前台隐藏，「删除」会移除数据。
请先连接仓库以加载车型。

02

联系渠道

配置 WhatsApp、邮箱，以及前端「在线咨询」所用的客服对话 Token。
Chat Token 用于前端访客创建对话 Issue，请使用细粒度 Token且仅授权该仓库的 Issues 读写（不要给 contents/repo 全权限），即使泄露也改不了网站文件。访客消息将以 Issue 形式存入仓库。

客户询盘 · 客服对话

访客通过前端「在线咨询」发起的对话会以 GitHub Issue 形式出现在此，客服可直接回复，回复会实时显示给访客。
连接仓库后加载对话。

连接仓库后查看仓库状态。
